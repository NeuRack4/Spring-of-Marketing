# Docs — 프로젝트 문서

프로젝트 관련 문서, API 명세, 회의록 등을 관리하는 폴더.

## 문서 목록

| 문서     | 설명                          | 위치                       |
| -------- | ----------------------------- | -------------------------- |
| PRD      | Product Requirements Document | `/PRD_SpringOfMarketer.md` |
| API 명세 | 서비스 간 API 스펙 문서       | `docs/api/` (예정)         |
| ERD      | 데이터베이스 설계             | `docs/erd/` (예정)         |
| 회의록   | 팀 회의 기록                  | `docs/meetings/` (예정)    |

## 문서 작성 가이드

- API 명세는 OpenAPI(Swagger) 형식 사용
- ERD는 dbdiagram.io 또는 Mermaid 활용
- 회의록은 `YYYY-MM-DD-제목.md` 형식으로 작성
